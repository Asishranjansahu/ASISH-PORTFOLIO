## 📌 Overview

This repository contains the source code for my personal developer portfolio. It is designed to provide recruiters, collaborators, and fellow developers with an interactive summary of my journey, technical skill set, featured engineering projects, and professional background.

### 🌟 Key Highlights
- ⚡ **High Performance:** Built on Vite for lightning-fast loads and optimized asset bundling.
- 📱 **Fully Responsive:** Pixel-perfect layout across mobile, tablet, and desktop screens.
- 🎨 **Modern UI/UX:** Clean design, smooth transitions, and modern Tailwind styling.
- 🛠 **Project Showcase:** Interactive cards featuring live demo links, GitHub source repositories, and technology badges.
- 📬 **Contact Integration:** Functional channel for hiring, inquiries, and collaboration.

## 📂 Project Structure

```text
ASISH-PORTFOLIO/
├── public/                # Static assets, favicon, resume, and icons
├── src/
│   ├── assets/            # Project images and illustrations
│   ├── components/        # Reusable UI components (Navbar, Footer, Cards, etc.)
│   ├── App.jsx            # Main application layout
│   ├── index.css          # Global styles & Tailwind directives
│   └── main.jsx           # Vite application entry point
├── index.html             # HTML entry template
├── postcss.config.js      # PostCSS configuration
├── tailwind.config.js     # Tailwind CSS design system config
├── vite.config.js         # Vite bundler configuration
├── package.json           # Project dependencies and npm scripts
└── README.md              # Project documentation

⚡ Getting Started
Follow these steps to run the portfolio locally on your machine.
Prerequisites
Make sure you have Node.js (v16.x or higher) and npm installed:
code
Bash
node -v
npm -v
Installation
Clone the repository:
code
Bash
git clone git@github.com:Asishranjansahu/ASISH-PORTFOLIO.git
cd ASISH-PORTFOLIO
Install dependencies:
code
Bash
npm install
Start the local development server:
code
Bash
npm run dev
Open in browser:
Open your browser and navigate to http://localhost:5173.
🛠 Available Scripts
In the project root directory, you can run:
Command	Description
npm run dev	Starts the Vite development server with Hot Module Replacement (HMR)
npm run build	Compiles and optimizes production-ready static assets into dist/
npm run preview	Locally preview the generated production build
